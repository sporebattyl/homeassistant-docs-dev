## 🛠️ **TROUBLESHOOTING**

### **🔄 Dashboard Not Loading**
1. **Check Internet**: Ensure connection to Home Assistant
2. **Clear Cache**: Refresh browser (Ctrl+F5)
3. **Check HA Status**: Verify Home Assistant is running
4. **Validate Entities**: Run validation script

### **📊 Missing Entities**
1. **Entity Unavailable**: Wait for sensors to come online
2. **Restart Required**: Some entities need HA restart
3. **Configuration**: Check packages are loaded
4. **Network**: Verify device connectivity

### **🎛️ Control Issues**
1. **Permissions**: Ensure user has control permissions
2. **Device Status**: Check if devices are powered on
3. **Network**: Verify device network connectivity
4. **Integration**: Confirm integrations are properly configured
